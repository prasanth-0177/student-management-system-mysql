
# Student Management System using MySQL

## About the Project
A beginner-level database project designed to manage student information using MySQL.

## Technologies Used
- MySQL
- SQL

## Features
- Store student details
- View all student records
- Search students based on marks
- Sort students by marks
- Count students department-wise

## Database Table
The `students` table contains:
- student_id
- first_name
- last_name
- email
- department
- marks

## SQL Concepts Used
- CREATE DATABASE
- CREATE TABLE
- INSERT INTO
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- COUNT()

## How to Run
1. Open MySQL Workbench.
2. Open the `student_management_system.sql` file.
3. Execute the SQL script.
4. Run the queries to view student records.
